Letzte Aktualisierung / Last updated: 2026-03-24

## Deutsch

### Übersicht

DOM Extractor Pro arbeitet vollständig lokal in deinem Browser.
Es werden keine Daten an externe Server gesendet. Kein Tracking, keine Analyse, keine Werbung.

### Welche Daten werden gespeichert?

- **Einstellungen** (Filter, Profil, Theme): Lokal im Browser via `chrome.storage.sync`
- **Snapshots** (extrahierte Inhalte): Lokal im Browser via `chrome.storage.local`
- **Vorschau-Daten**: Temporär in `chrome.storage.local`, werden nach dem Anzeigen gelöscht

### Netzwerkanfragen

DOM Extractor Pro stellt **keine** Netzwerkanfragen. Die Extension funktioniert vollständig offline.

### Berechtigungen

| Berechtigung | Zweck |
|-------------|-------|
| `activeTab` | Zugriff auf den DOM der aktuellen Seite bei Klick |
| `scripting` | Content Script für Element-Picker und Extraktion injizieren |
| `storage` | Einstellungen und Snapshots lokal speichern |
| `contextMenus` | Rechtsklick-Menü für schnellen Zugriff |

### Drittanbieter

DOM Extractor Pro verwendet **keine** Drittanbieter-Dienste, externen Bibliotheken oder CDNs.
Alle Ressourcen (Icons, Styles, Scripts) sind lokal in der Extension enthalten.

### Deine Rechte

- Du hast jederzeit volle Kontrolle über deine Daten
- Alle Daten können über die Browser-Einstellungen gelöscht werden
- Deinstallation der Extension entfernt alle gespeicherten Daten
- Der Quellcode ist vollständig einsehbar

### Kontakt

Fragen zum Datenschutz: [GitHub Issues](https://github.com/HalloWelt42/real-dom-extract-chrome-extention/issues)

## English

### Overview

DOM Extractor Pro works entirely locally in your browser.
No data is sent to external servers. No tracking, no analytics, no ads.

### What data is stored?

- **Settings** (filters, profile, theme): Locally in the browser via `chrome.storage.sync`
- **Snapshots** (extracted content): Locally in the browser via `chrome.storage.local`
- **Preview data**: Temporarily in `chrome.storage.local`, deleted after viewing

### Network requests

DOM Extractor Pro makes **no** network requests. The extension works fully offline.

### Permissions

| Permission | Purpose |
|-----------|---------|
| `activeTab` | Access the DOM of the current page on click |
| `scripting` | Inject content script for element picker and extraction |
| `storage` | Store settings and snapshots locally |
| `contextMenus` | Right-click menu for quick access |

### Third-party services

DOM Extractor Pro uses **no** third-party services, external libraries, or CDNs.
All resources (icons, styles, scripts) are bundled locally in the extension.

### Your rights

- You have full control over your data at all times
- All data can be deleted via browser settings
- Uninstalling the extension removes all stored data
- The source code is fully transparent

### Contact

Privacy questions: [GitHub Issues](https://github.com/HalloWelt42/real-dom-extract-chrome-extention/issues)
