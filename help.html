DOM Extractor Pro

Prepare web content for AI processing

Capture Modes

Picker

Starts a visual element picker. Move the mouse over the page - a blue frame highlights the element under the cursor. Click to capture, ESC to cancel.

Ideal for: individual paragraphs, tables, sidebars, specific areas.

Selection

Captures currently selected text on the page. First select the desired area, then open the popup and click "Selection".

Ideal for: exact text passages, quotes, individual paragraphs.

Full Page

Captures the complete DOM of the current page - including all dynamically generated content (Single Page Apps, AJAX-loaded data, etc.). Configured filters are applied afterwards.

Ideal for: complete page capture, dynamic web apps, pages with JavaScript-generated content.

Smart Extract

Uses readability heuristics to automatically identify the main content. Systematically removes navigation, ads, footers, sidebars, cookie banners, and other non-content elements.

Ideal for: news articles, blog posts, documentation pages.

Profiles

Quick Configuration

  • AI-Optimized - Markdown output, maximum cleanup. All filters active.
  • Developer - HTML output, only JS removed. Structure fully preserved.
  • Minimal - HTML output, no filters. The DOM as-is.
  • Custom - Automatically saves your manual settings. Click to restore.

Output Formats

Clean HTML

Cleaned HTML with structure. Tables, lists and headings preserved as tags.

Markdown

Tables become pipe tables, headings become # notation, lists become bullet points.

Plain Text

Only visible text. Tables are output tab-separated.

JSON

Structured tree with tags and text. Tables extracted as arrays with header keys.

Filters

Remove JS

Removes all script tags and event handler attributes. Almost always useful for AI processing.

Remove CSS

Removes style tags, stylesheet links, inline styles and class attributes. Massively reduces output.

Remove SVG

Removes inline SVG graphics and canvas elements.

Remove images

When enabled: images are completely removed. When disabled (default): images are replaced with [IMG: alt-text] placeholders.

Data attributes

Removes data-*, aria-* and role attributes. Unnecessary token overhead for AI processing.

Empty tags

Iteratively removes HTML elements that contain neither text nor children after filtering.

Nav links

Removes navigation elements: nav tags, breadcrumbs, pagination, menus and sidebars.

Forms

Removes all form elements: form, input, select, textarea, button, fieldset and legend.

Flatten containers

Reduces nested wrapper elements. A div containing only a single child div gets unwrapped. Saves significant tokens in HTML mode.

Duplicate text

Detects and removes identical text blocks appearing multiple times. Disabled by default.

Normalize whitespace

Replaces multiple spaces with single spaces, reduces excessive blank lines, and removes leading whitespace.

Max. Characters

Limits output to a maximum character count. Default: 100,000,000 (practically unlimited).

Preview

Opens the extraction result in a new tab. In HTML mode, you can switch between rendered view and source code.

Snapshots

Each extraction is automatically saved as a snapshot (max. 10). Click to load, X to delete. Snapshots persist across browser restarts.

Tip: For best AI preparation, use the "AI-Optimized" profile with Markdown format.
